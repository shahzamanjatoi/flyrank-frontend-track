# Flyrank Frontend Track

Frontend application for the Flyrank frontend track.

## Planned stack

- React
- Vite
- TypeScript
- Tailwind CSS

## Setup

1. Clone this repository.
2. Install dependencies with `npm install`.
3. Start the development server with `npm run dev`.
4. Open the URL printed in the terminal (typically `http://localhost:5173`).

## Status

Scaffolding in progress. App source and tooling are not in the repo yet.
