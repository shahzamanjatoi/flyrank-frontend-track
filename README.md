# Flyrank Frontend Track

Frontend application for the Flyrank frontend track.

**Status:** scaffolding only. This repository does not yet contain app source, `package.json`, or Vite tooling, so `npm install` and `npm run dev` will fail until that lands.

## Planned stack

- React
- Vite
- TypeScript
- Tailwind CSS

## Setup (after scaffolding)

Prerequisites: Node.js with npm (Vite 5 typically needs Node 18+).

1. Clone this repository.
2. Install dependencies with `npm install`.
3. Start the development server with `npm run dev`.
4. Open the URL printed in the terminal (typically `http://localhost:5173`).

| Command | Purpose |
| --- | --- |
| `npm run dev` | Start the Vite development server |
| `npm run build` | Type-check and produce a production build |
| `npm run lint` | Run the project linter |
